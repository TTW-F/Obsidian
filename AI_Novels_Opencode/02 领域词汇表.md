# 02 领域词汇表

> [!warning] 纪律
> 来源 `F:\AI_Novels_OpenCode\CONTEXT.md`。写文档/票据/代码/测试命名**一律用本表术语，不得自造同义词**（团队会打回）。右侧"避免的说法"是反例。

| 术语 | 定义 | 避免的说法 |
|---|---|---|
| [[作品 Work]] | 一个目录 + 一个 git 仓库，一级目录：大纲/细纲/正文/设定/时间线/伏笔/素材/meta | 项目/书/内容树 |
| 章节 | 正文目录下 md 文件，可嵌套卷/册；文件名/meta 锚定剧情位置 | 内容节点 |
| 工作区 | 作品目录的当前磁盘内容；Agent 与作者写的都是这一份文件 | 候选/草稿仓库 |
| HEAD | 已提交的正式内容；版本历史 = git log | 正式库 |
| [[Keep 与 Undo\|Keep / Undo]] | 按文件 git commit / 恢复到 HEAD | merge/approve/驳回 |
| 防剧透 | 防止 AI 提前用未揭晓剧情；**零系统机制**，四层 | 权限/隔离 |
| 唯一提交服务 | 所有写路径收敛的唯一入口；每次触发索引同步 | 事务中心 |
| [[主管与专家\|主管（主编）]] | 常驻主 agent，作者副手；放权时承担作家身份 | 调度器 |
| [[主管与专家\|专家会话]] | 具名常驻专家的独立会话，保有该专家上下文 | 一次性子代理 |
| [[委派]] | 主编向专家发有归因的工作请求，专家回传结果 | 匿名 subagent |
| C 会话聚合 | C Gateway conversation + Snapshot/Feed/SSE（Session V2 之上的产品投影） | API 网关 |
| [[Attempt]] | Session 整段自行忙完的一次可审计执行；中间 provider step 不打断作者回合 | 轮次/turn |
| 放权 | 配置型（跳过 ask，边界仍在）/ 对话型（过程自主，交稿 diff 确认） | 权限提升 |
| 离开兜底 | 作者不在场：工作区 diff 堆积（绝不自动提交）+ 单指令单任务 + 时间盒 | 自动执行 |
| 目标 Goal | 作者显式设置的持续追求结果及完成标准 | 创作阶段 |
| [[Queue 与 Steer\|排队 Queue]] | Agent 工作时 Composer 的默认投递；请求等待当前工作结束 | 插队 |
| [[Queue 与 Steer\|调整方向 Steer]] | 作者显式点击向正在工作的 Agent 补充方向；非默认发送 | 普通消息 |

## 高频缩写
- **C Gateway**：产品层命令/事件聚合入口（`/agent/conversations/:id/runs` 等）。
- **契约矩阵**：前端 API 兼容契约的逐端点/事件形状校验（Seam A 测试面）。
- **铁律**：见 [[01 项目是什么#设计铁律]]。

> [!tip] 用法
> 表格里 `[[...]]` 是可点链接；相关术语已互相链接（如 委派 ↔ 主管与专家）。看代码时遇到陌生词先回本表。
