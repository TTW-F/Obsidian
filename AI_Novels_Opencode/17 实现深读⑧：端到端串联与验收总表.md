## 1. 一条命令的完整一生（Mermaid 端到端）

```mermaid
flowchart LR
    A[作者在编辑器点发送] --> B[agent-gateway-routes POST /runs<br/>⑤命令总线]
    B --> C[幂等键去重]
    C --> D[adapter.startRun<br/>③]
    D --> E[host.prompt = SessionV2.prompt<br/>持久化准入]
    E --> F[OpenCode 执行:模型+工具写文件]
    F --> G[work-repository / commit-service<br/>①写文件+git]
    G --> H[index hook 同步检索索引<br/>⑥写后可见]
    F --> I[observeRunEvents 收原生事件]
    I --> J[mapOpenCodeEvent 翻译<br/>③]
    J --> K[adapter.emit]
    K --> L[RunStore 投影 + SSE Hub<br/>④]
    L --> M[SSE 帧流]
    M --> N[前端 projection 薄投影<br/>⑦]
    N --> O[三栏 UI:信息流/树/编辑器]
```

## 4. 给实习生的下一步

- 想跑起来看真实链路：按 [[07 机器拓扑与红线]]，只在 Windows 开发机改代码，改完到 `192.168.31.35` 验证（只读，不编辑）。
- 想加新能力：先想清它属于哪一层（领域层 novel-core / 桥接 novel-server / 前端 novel-web），别越层。
- 任何写操作都要经过 ① 的 commit 服务，这样 ⑥ 索引、③ 投影才会自动一致。

> 验收达成标准：以上 22 题你都能用自己的话答出"函数名 + 它干什么 + 为什么这样设计"，即视为完全理解本项目实现。
